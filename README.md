## 🚀 Featured projects

### 🌱 Ethico

Ethico explores how consumers could access **source-backed information about products and the companies behind them** by scanning a product barcode.

The current application includes:

- Flutter mobile frontend
- FastAPI backend
- EAN barcode scanning
- SQLite persistence
- Open Food Facts integration
- Source and provenance handling
- Automated backend and frontend testing
- GitHub Actions CI
- Repository privacy and security checks

The project is under active development. Future work includes expanding source coverage and exploring how AI could assist with evidence-based analysis without replacing source transparency.

👉 [View Ethico on GitHub](https://github.com/AndersWahlberg/ethico-app)
